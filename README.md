# ConsumeWise Browser Extension  
ConsumeWise: Make every purchase a conscious choice! 🌍💚

**ConsumeWise** is a browser extension designed to enhance transparency and trust in consumer goods by providing health and sustainability scores for products directly on e-commerce websites. It empowers consumers to make informed choices by offering personalized insights into the environmental, societal, and health impacts of products.

---

## Features  

- **Health and Sustainability Scores**  
  Displays intuitive scores (e.g., **Health: 80/100**, **Sustainability: 70/100**) directly on product pages.  

- **Alternative Suggestions**  
  Suggests healthier and more sustainable alternatives based on product analysis.  

- **Detailed Reports**  
  Provides instant access to in-depth product impact reports for a complete understanding of health, environmental, and societal effects.  

- **E-commerce Integration**  
  Seamlessly works with e-commerce websites to overlay product scores and recommendations.  

---

## Installation  

1. Clone this repository:  
   ```bash
   git clone (https://github.com/yashdavkhar7020/ConsumeWise-Scores)
   cd consume-wise-extension

   Open your browser (Microsoft Edge).

   Go to the Extensions page:

   Edge: Navigate to edge://extensions/.
   Enable Developer Mode (toggle the switch at the bottom of the page).

   Click Load Unpacked and select the consume-wise-extension folder.

   The extension will be installed and activated.

##Usage
Visit any supported e-commerce website (e.g., Amazon, Flipkart).
View health and sustainability scores directly on the product page.
Click the ConsumeWise icon in the browser toolbar to access:
Detailed impact reports.
Suggested alternative products.
